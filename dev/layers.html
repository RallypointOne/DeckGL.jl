Layers

Every deck.gl layer is available, generated from deck.gl’s own prop tables. Each example below is self-contained and ready to copy-paste.

Props may be written snake_case or camelCase — get_fill_color and getFillColor are the same prop — and anything left unset keeps deck.gl’s own default. Any accessor takes a constant, a column name as a Symbol (or a Vector{Symbol} to combine several columns), or JS(...) for a JavaScript function.

Every example draws on a basemap. map_style takes any MapLibre style URL; Carto’s are free and need no API key.

BASEMAP = "https://basemaps.cartocdn.com/gl/positron-gl-style/style.json"
"https://basemaps.cartocdn.com/gl/positron-gl-style/style.json"

Omit map_style for a blank background — see Getting Started for the other styles and what a basemap costs.

Core Layers

Core layers draw one shape per record, with no aggregation.

ScatterplotLayer

Circles at given coordinates.

data = (
    lng  = [-122.45, -122.42, -122.38, -122.50, -122.47, -122.41],
    lat  = [37.78, 37.76, 37.79, 37.77, 37.80, 37.75],
    size = [80, 200, 120, 300, 150, 250]
)

Deck(
    ScatterplotLayer(
        data = data,
        get_position = [:lng, :lat],
        get_radius = :size,
        get_fill_color = [255, 140, 0, 200],
        radius_min_pixels = 3,
        tooltip = [:size]
    ),
    initial_view_state = ViewState(longitude=-122.44, latitude=37.77, zoom=12),
    map_style = BASEMAP
)

IconLayer

Sprites from an icon atlas. icon_mapping names the regions of the atlas image, and get_icon picks one per record.

        icon_mapping = Dict("marker" => Dict(

Aggregation Layers

Aggregation layers bin records before drawing, so what you see is one shape per bin rather than per record. They read every record through its accessor, which is why they receive data differently from the layers above — see Getting Started.

Picking one selects a bin, so a tooltip shows the bin’s own aggregated values.

HexagonLayer

Hexagonal bins, optionally extruded by an aggregate.

earthquakes = let n = 200
    (lng = -122.4 .+ 0.2 * randn(n),
     lat = 37.8 .+ 0.15 * randn(n),
     magnitude = 1.0 .+ 3.0 * rand(n))
end

Deck(
    HexagonLayer(
        data = earthquakes,
        get_position = [:lng, :lat],
        get_elevation_weight = :magnitude,
        radius = 500,
        elevation_scale = 50,
        extruded = true,

HeatmapLayer

A density surface, computed on the GPU. It renders through a framebuffer rather than geometry, so it has nothing pickable.

incidents = let n = 500
    lng1 = -122.45 .+ 0.03 * randn(n ÷ 2); lat1 = 37.78 .+ 0.02 * randn(n ÷ 2)
    lng2 = -122.40 .+ 0.02 * randn(n ÷ 2); lat2 = 37.76 .+ 0.015 * randn(n ÷ 2)
    (lng = vcat(lng1, lng2), lat = vcat(lat1, lat2), severity = 1.0 .+ 4.0 * rand(n))
end

Deck(
    HeatmapLayer(
