Widgets

Widgets are HTML controls deck.gl overlays on the canvas — zoom buttons, a compass, a screenshot button, a popup. All 15 are available, generated from deck.gl’s own prop tables.

Pass them to Deck with the widgets keyword:

Deck(layer, widgets = [ZoomWidget(), CompassWidget()])

Widgets are styled by a deck.gl stylesheet that pages include only when they actually contain a widget. Every example below sits on a Carto basemap, passed as map_style — see Getting Started.

Common Props

Every widget accepts these:

Prop Default Description
id per widget Identifier, unique within a deck
placement per widget "top-left", "top-right", "bottom-left", "bottom-right"
style Dict() Inline CSS, including the --button-* custom properties
class_name "" Extra CSS class
view_id nothing Bind the widget to one view in a multi-view deck

The tables below list what each widget adds on top of those.

Camera

ZoomWidget

Zoom in and out buttons.

demo(ZoomWidget())
NoteZoomWidget props

In addition to the common props:

Prop
on_zoom
orientation
transition_duration
zoom_axis
zoom_in_label
zoom_out_label

Descriptions and accepted values are in the deck.gl widget reference.

Lay the buttons out horizontally and move them:

demo(ZoomWidget(placement = "bottom-left", orientation = "horizontal",
                transition_duration = 400))

CompassWidget

A compass rose showing the current bearing. Click it to reset to north, then to flatten the pitch.

demo(CompassWidget(); pitch = 45, bearing = -30)

GimbalWidget

ResetViewWidget

Returns the camera to where it started. Give it an explicit initial_view_state to reset somewhere other than the deck’s own.

ScrollbarWidget

A scrollbar that pans the view within content_bounds, given as two corners, [[min_lng, min_lat], [max_lng, max_lat]].

demo(
    ScrollbarWidget(content_bounds = [[-122.6, 37.6], [-122.3, 37.9]],
                    orientation = "vertical", placement = "top-right"),
    ScrollbarWidget(id = "scroll-x", content_bounds = [[-122.6, 37.6], [-122.3, 37.9]],
                    orientation = "horizontal", placement = "bottom-left"),
)

Two widgets of the same type need distinct ids, as above.

Display

FullscreenWidget

Expands the deck’s container to fill the screen.

demo(FullscreenWidget())

In a notebook or on this page the deck lives in an iframe, so fullscreen applies to that frame.

ThemeWidget

Switches the widgets between light and dark. initial_theme_mode may be "auto", "light", or "dark"; light_mode_theme and dark_mode_theme hold the CSS custom properties each mode applies.

demo(ThemeWidget(initial_theme_mode = "auto"), ZoomWidget(), CompassWidget())

Information

InfoWidget

A tooltip anchored to the picked object. get_tooltip is a JavaScript function of the picking info, and mode is "hover" or "click".

demo(InfoWidget(
    mode = "click",
    get_tooltip = JS("info => info.index >= 0 ? {html: `<b>index</b> \${info.index}`} : null"),
))

For the common case of showing a few columns, the layer’s tooltip prop is simpler — it ships the columns for you and needs no JavaScript:

ScatterplotLayer(data = points, get_position = [:lng, :lat], tooltip = [:name, :size])
NoteInfoWidget props

In addition to the common props:

Prop
arrow
get_tooltip
mode
offset

Descriptions and accepted values are in the deck.gl widget reference.

ContextMenuWidget

A right-click menu. Each entry is a label and a key, and on_menu_item_selected receives the key.

demo(ContextMenuWidget(
    menu_items = [
        Dict("label" => "Zoom in",   "key" => "zoom-in"),
        Dict("label" => "Copy point", "key" => "copy"),
    ],
    on_menu_item_selected = JS("key => console.log('selected', key)"),
))

Right-click the map to open it.

Custom Controls

These three are building blocks: they render a control and hand the event back to JavaScript, so what they do is up to you.

IconWidget

A button with your own icon. icon is an image URL — a file, or an inlined SVG as here.

demo(IconWidget(
    icon = star_icon,
    label = "Say hello",
    on_click = JS("() => console.log('icon widget clicked')"),
))
NoteIconWidget props

In addition to the common props:

Prop
color
icon
label
on_click

Descriptions and accepted values are in the deck.gl widget reference.

ToggleWidget

A two-state button, with a separate icon and label for the on state.

demo(ToggleWidget(
    icon = dot_icon,    label = "Markers off",
    on_icon = star_icon, on_label = "Markers on",
    initial_checked = false,
    on_change = JS("checked => console.log('checked:', checked)"),
))
NoteToggleWidget props

In addition to the common props:

Prop
color
icon
initial_checked
label
on_change
on_color
on_icon
on_label

Descriptions and accepted values are in the deck.gl widget reference.

SelectorWidget

A dropdown. options is a list of label/value pairs.

demo(SelectorWidget(
    options = [
        Dict("label" => "Orange", "value" => "orange"),
        Dict("label" => "Blue",   "value" => "blue"),
    ],
    initial_value = "orange",
    on_change = JS("value => console.log('picked', value)"),
))

Reacting to a selection means changing layer props from JavaScript. For anything driven from Julia, rebuild the Deck and re-render instead.

In addition to the common props:

Combining Widgets

Widgets stack in the order given, grouped by placement.

demo(
    ZoomWidget(placement = "top-left"),
    CompassWidget(placement = "top-left"),
    ResetViewWidget(placement = "top-left"),
    FullscreenWidget(placement = "top-right"),
    ScreenshotWidget(placement = "top-right"),
    ThemeWidget(placement = "bottom-right");
    pitch = 40, bearing = -25,
)
